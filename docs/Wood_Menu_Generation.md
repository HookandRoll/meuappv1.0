# Textura de madeira dos menus

Gerada pela ferramenta integrada de geração de imagens, usando a imagem fornecida pelo usuário como direção visual descrita no prompt. O arquivo utilizado pelo aplicativo está em [wood-menu.png](../assets/ui/wood-menu.png), 2172 × 724 pixels. O original gerado foi copiado para o projeto sem edição.

## Prompt utilizado

```text
Create a new tileable raster texture for the menu panels of a low-fantasy map editor game. Reference style: dark warm brown wood with long horizontal grain, elongated swirling knots and thin dark grain lines, like a wooden tabletop. Make it distinctly hand-drawn and hand-painted with fine ink outlines and muted brush shading, not a photograph, not glossy, not 3D. Flat straight-on orthographic material swatch filling the entire image edge to edge. Subtle low-contrast grain so ivory menu text remains easy to read. No border, no bevel, no objects, no letters, no symbols, no watermark. Seamlessly tile horizontally and vertically, uniform lighting, no vignette. Wide landscape texture, roughly 3:1 composition.
```
