FAERIE MOOT
A true type font by P.D. Magnus
www.fontmonkey.com

This full keyboard font is the kind of typeface that the Seelie Court uses when sending subpoenas. It comes in an ornate version and a simple version that leaves out all the stray dots.

Faerie Moot is copyright 2005 by P.D. Magnus.
